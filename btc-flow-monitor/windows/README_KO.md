# BTC FLOW Windows 실행

1. ZIP 파일을 압축 해제합니다. 압축파일 안에서 바로 실행하지 마세요.
2. `btc-flow-monitor/windows/START_BTC_FLOW.cmd`를 더블클릭합니다.
3. 첫 실행은 Python 3.12와 Python Launcher(파이썬 실행기)가 필요합니다.
   설치되지 않았다면 https://www.python.org/downloads/windows/ 에서 설치하세요.
4. 필요한 라이브러리를 최초 한 번 설치하고 브라우저를 자동으로 엽니다.
   주소: http://127.0.0.1:8080/
5. 검은 실행 창은 열어두세요. 종료는 해당 창에서 Ctrl+C입니다.
   다시 실행하면 저장된 계좌로 이어집니다.

실거래/거래소 키/클라우드 결제는 필요하지 않습니다. 모의거래 전용입니다.
초기 데이터 수집에는 약 1~2분 걸릴 수 있습니다. WAIT_SOURCE는 수집 대기입니다.
가격은 실시간으로 수신하고 판단 목표는 1초입니다. 고래/파생 정보는 약 60초
주기로 수집하므로 모든 고래 거래를 즉시 감지하는 시스템은 아닙니다.
PC/인터넷을 켜두고 Windows 절전 모드를 해제하세요.

저장 위치: `%LOCALAPPDATA%\BTC_FLOW_PAPER\state`
이 폴더를 삭제하면 기존 실시간 실험 기록을 잃습니다. 프로그램 ZIP 폴더를
바꾸어도 같은 Windows 사용자라면 계좌 기록은 이어집니다. 프로그램 업그레이드는
종료 후 하세요. 두 번 실행하면 두 번째 실행은 중복 방지로 차단됩니다.
정상 종료 후 state 폴더 전체를 복사해 백업할 수 있습니다.

기존 GitHub 모의계좌와 별도로 시작하는 실시간 실험입니다. 수익성 미검증.
현재 화면은 해당 PC에서만 열립니다. 휴대폰 외부 접속은 아직 구성하지 않았습니다.

## 기존 대시보드 연결
실행하면 기존 BTC FLOW 대시보드가 http://127.0.0.1:8080/ 에 열립니다. 홈의 6개 엔진 비교표는 PC 계좌로 1초마다 갱신합니다. 나머지 메뉴는 다운로드 당시 GitHub 저장 기록입니다. 기존 인터넷 주소에서 PC 실시간 계좌를 볼 수는 없습니다.
