WEXA 사용 순서

    가입할 때는 근로자 유형을 선택하세요. 승인 완료 후 현장으로 이동하세요.
    SAFE GUIDE · 본체 기능 미수정
    운영 기준 안내

    승인된 공고만 출근 대상입니다. 허위 공고, 불법 고용 목적, 임금 미지급 위험이 확인되면 이용이 제한될 수 있습니다.

    1. 공고 확인현장 정보와 조건 확인
    2. 근무 신청근로자가 신청 접수
    3. 업체 확인관리자가 신청 검토
    4. 승인 후 출근승인된 현장만 출근
    회원가입
    가입 유형에 필요한 최소 정보만 입력합니다.
    업체 등록 운영 기준

    허위 업체, 불법 인력 알선, 임금 미지급, 불법 고용 목적의 가입은 허용되지 않습니다.

    등록 정보는 운영 확인을 위해 사용됩니다.

    첫 가입 업체 3회 무료

    첫 가입 업체는 최초 3회 공고 등록 및 운영 수수료가 무료로 제공됩니다.

    근무 완료 기준 수수료 정책

    WEXA 운영 수수료는 실제 근무 완료가 확인된 경우에만 확정됩니다.

    근무가 완료되지 않은 경우에는 사유와 관계없이 운영 수수료를 반환합니다.

    ※비사업자는 운영 확인 후 제한적으로 테스트할 수 있습니다.
    ※외국인등록번호는 개인정보 보호를 위해 정부 API 진위 확인에만 1회성으로 사용되며, 플랫폼 DB에는 절대로 저장되지 않고 즉시 파기됩니다.
    관리자 로그인
    등록한 연락처와 비밀번호로 접속합니다.
    근로자 로그인
    등록한 연락처와 비밀번호로 접속합니다.
    새 공고 등록
    등록된 공고는 운영 기준에 따라 확인 후 게시됩니다.
    공고 등록 기준

    허위 공고, 불법 고용 목적 공고, 임금 미지급 위험 공고, 위험·부적절 현장 공고는 게시가 보류될 수 있습니다.
